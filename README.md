## Assignment Descriptions

### 1. JavaScript Calculator
A basic calculator that performs addition, subtraction, multiplication, and division using JavaScript functions and conditional logic.

### 2. DOM To-Do List
A dynamic To-Do List that allows users to add tasks, mark tasks as completed, and delete tasks using JavaScript DOM manipulation.

### 3. JavaScript Form Validation
A registration form that validates name, email, phone number, and password fields and displays appropriate error messages.

### 4. React Profile Card
A React profile card created using reusable components and Props. It displays a name, profile image, and description.

### 5. Controlled React Form
A controlled form built with React state. User-entered information is stored in state and displayed in real time.

### 6. React Counter
A simple counter application demonstrating React's `useState` hook with increment, decrement, and reset functionality.
